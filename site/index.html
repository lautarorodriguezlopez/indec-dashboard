    Todos los datos, para bajar y explorar

    Cada número del tablero sale de una fuente oficial. Acá podés ver el estado de cada una, filtrar los datos en el explorador y bajarlos.

    Explorador

    Elegí un dataset, filtralo, graficalo y bajá lo que necesites en CSV. Todo corre en tu navegador: no se envía nada a ningún servidor.

    El motor de consultas pesa unos 8 MB: se baja solo si lo abrís. Con datos móviles, conviene usar wifi.

    INDEC · Catálogo API-INDEC

    BCRA · API de Estadísticas Monetarias

    Los archivos están en formato Parquet: se abren con Python (pandas), R, DuckDB o Power BI.
